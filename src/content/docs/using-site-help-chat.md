# Using the help assistant

The help assistant answers questions about how to use this site, drawing only from these help guides.

## Asking a question

Select the help icon in the top navigation bar to open the assistant. Type a question in plain language, such as "How do I add another email address?", and press Enter. The answer includes links to the guides it used, so you can read the full instructions.

## What the assistant can and can't do

The assistant only knows what is written in the help guides. It can't see your account, change settings, or answer questions about other topics. If it can't find an answer, it says so; contact an administrator for help. To keep the service available for everyone, the number of questions you can ask per minute is limited.
