## Users & roles
- **Guest**: signed in, not yet a member; can only submit an access request.
- **Member**: approved user; sees member pages.
- **Editor**: staff; Admin area Status and Log Viewer (extend for content tools).
- **Admin**: user management, permissions, settings.
- **Owner**: everything, including managing other Owners.
